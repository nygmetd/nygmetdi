# AP3 - C.A.L.S Credit Sorter
- GenerateCredits(): returns a vector of 20 random ints from 0 to 100.
- FoundAmount(int target, vector<int> v): returns how many times target
  appears in the vector (0 if it is not found).
- SortCredits(bool ascend, vector<int> v): returns a sorted copy using bubble
  sort; ascending if ascend is true, descending otherwise.
- PrintStats(vector<int> sorted): prints the lowest, highest, average and
  median of a sorted vector.

## How to run
g++ -std=c++17 main.cpp -o main
./main
