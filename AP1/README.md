# AP1 - Welcome Message

This program asks the user for their name and greets them. Then it reads two
integers (A and B) and prints their sum, product, division (as a float) and
remainder. If B is 0, it prints a message instead of dividing. At the end it
says goodbye to the user.

## How to run

g++ -std=c++17 main.cpp -o main
./main

## Example

Input: name "Anna", A = 7, B = 2
Output: Sum: 9, Product: 14, Division: 3.5, Remainder: 1
